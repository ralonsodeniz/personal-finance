Welcome to the user-help information space. This is the task-oriented home for
future product guidance, kept separate from the developer architecture guide.

The product is currently in its architecture and workspace-bootstrap phase.
That means this site can explain the documentation structure and future scope,
but it does not yet document working finance workflows, identity setup, imports,
or native app behavior.

For the current scope, read [Documentation status](getting-oriented/documentation-status).

If you are implementing the platform, switch to the
[developer guide](/developers/intro) instead.
